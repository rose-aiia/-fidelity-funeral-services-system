# Brand assets

The site uses these files from `frontend/public/`. The ones marked *interim* were drawn for the prototype and should be replaced by the originals; the code does not change when you swap a file for one with the same name.

| File | What it is | Needs |
| --- | --- | --- |
| `brand/mark.svg` | The scales symbol in brand red. Header (light surfaces), favicon | *Interim redraw.* Original SVG, square-ish, transparent background |
| `brand/mark-light.svg` | The same symbol in white, used on the dark header, footer and sign-in panel | *Interim.* White version of the original |
| `brand/logo.svg`, `brand/logo-light.svg` | The full stacked logo ("FIDELITY LIFE / ASSURANCE OF ZIMBABWE") | *Interim.* Original SVG, or a PNG at least 1200px wide, transparent background |
| `hero/hero.jpg` | Landing-page hero photograph | At least 2400px wide, about 16:9, calm sky on the left for the headline, under about 300 KB. Not present yet: the hero shows an original dusk illustration until it is added, and falls back to it if the file fails to load |

Guidance for the hero photograph: a family seen from behind at golden hour, warm light, no text in the picture (the headline is real text), and nothing that reads as another business (a building site, a bank, an insurance icon). Use a photograph the organisation owns or has licensed; images found through a web search are not licensed for reuse.

The header sets the name next to the mark as live text, so it stays sharp at every size.
